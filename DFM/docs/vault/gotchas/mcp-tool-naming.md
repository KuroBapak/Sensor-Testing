# Gotcha: Laravel Boost tool naming pakai double underscore

Nama tool MCP formatnya `laravel-boost__nama-tool` (dua underscore),
bukan satu. Model kadang salah tulis di percobaan pertama, tapi
self-correct otomatis di percobaan berikutnya setelah baca error.

Tidak perlu diperbaiki manual — cuma informasi kalau muncul lagi,
supaya tidak dikira bug baru.
